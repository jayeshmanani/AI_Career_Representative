What this page does

This is a direct chat interface for the backend endpoint. It sends your question to /chat and renders the assistant response in the same window.

Best questions to try

“Tell me about the candidate’s experience in one paragraph.”
“Which tools or technologies are mentioned?”
“What job titles or roles appear in the resume?”
“Which certifications are listed?”

Behavior

  • No hallucinations: the model should only answer from the parsed resume.
  • If a detail is missing, it should say the information is unavailable.
  • Responses appear as chat bubbles with loading feedback.
